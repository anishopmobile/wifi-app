# آنی وای‌فای (AniWiFi)

**انتقال فایل از آیفون و اندروید به کامپیوتر ویندوزی، بدون اینترنت، هاست، دامنه، حساب کاربری یا نصب برنامه روی گوشی.**

رایانه سرور HTTP را فقط داخل شبکه محلی اجرا می‌کند. مشتری QR را اسکن می‌کند و فایل‌ها را از Safari یا Chrome انتخاب می‌کند. انتقال قطعه‌قطعه است؛ بخش‌های دریافت‌شده را می‌توان بدون ارسال دوباره ادامه داد.

## امکانات

- برنامه دسکتاپ فارسی Tkinter، اجرای یک‌کلیکی پس از نصب و تولید خودکار QR برای نوبت تصادفی.
- ارسال هم‌زمان فایل‌های متعدد از Safari آیفون / Chrome اندروید؛ تنظیم ۱ تا ۶ درخواست هم‌زمان.
- بخش‌های ۴ مگابایتی، ارسال خارج از ترتیب، لغو، توقف، ادامه، تلاش مجدد و بررسی بخش‌های دریافت‌شده پس از قطع ارتباط.
- پشتیبانی فایل بزرگ (پیش‌فرض: حداکثر ۲۰ گیگابایت هر فایل و ۱۰۰ گیگابایت هر نوبت؛ قابل تنظیم)، محدودیت تعداد فایل و کنترل فضای آزاد دیسک.
- پوشه اختصاصی برای هر مشتری، نام فایل فارسی، جلوگیری از نام تکراری و جلوگیری از دسترسی به مسیر خارج از پوشه مقصد.
- لغو لینک مشتری قبلی هنگام شروع نوبت جدید، پاک‌سازی فایل‌های ناقص پس از پایان نوبت، حفظ فایل‌های کامل.
- انتخاب آدرس IPv4 محلی، تلاش برای ساخت Hosted Network قدیمی ویندوز، و QR جداگانه اتصال به وای‌فای در صورت موفقیت.
- وب‌اپ واکنش‌گرا، بدون CDN یا منابع اینترنتی، رابط راست‌به‌چپ با اولویت فونت Vazirmatn در صورت نصب بودن و جایگزین Tahoma.
- سرور بدون پورت مدیریتی عمومی یا کنترل از سمت مشتری. لاگ خطا با چرخش خودکار.

## نصب با فایل Setup ساخته‌شده در GitHub Actions

1. مخزن را در GitHub باز کنید و روی **Actions** بزنید.
2. اجرای موفق **Test and Windows Installer** برای آخرین commit شاخه `main` را باز کنید.
3. پایین صفحه در بخش **Artifacts**، فایل `AniWiFi-Windows-Installer` را دانلود و ZIP را استخراج کنید.
4. در ویندوز ۱۰ یا ۱۱ نسخه ۶۴ بیت، `AniWiFi-Setup-1.0.0.exe` را اجرا و نصب کنید. به اینترنت روی **رایانه مقصد نیازی نیست**؛ دانلود فایل نصب را می‌توان روی دستگاه دیگری انجام داد.
5. میانبر **AniWiFi** روی دسکتاپ ایجاد می‌شود. با اجرای آن، سرور محلی فعال و QR ظاهر می‌شود.

> توجه: فایل نصب امضای دیجیتال تجاری ندارد، بنابراین SmartScreen ویندوز ممکن است هشدار دهد. فقط فایل گرفته‌شده از Workflow رسمی همین مخزن را اجرا کنید.

## ساخت دستی خروجی نصبی روی ویندوز

پیش‌نیازهای سیستم سازنده: Windows 10/11 x64، Python 3.12 (گزینه Add Python to PATH)، اینترنت **فقط برای دانلود وابستگی‌ها در زمان ساخت**، PyInstaller و Inno Setup 6.

در PowerShell در ریشه مخزن:

```powershell
git clone https://github.com/anishopmobile/wifi-app.git
cd wifi-app
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt pyinstaller
python -m pytest -q
pyinstaller --noconfirm --clean --onedir --windowed --name AniWiFi --add-data "wifi_app/web;wifi_app/web" --collect-all aiohttp main.py
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\AniWiFi.iss
```

خروجی نهایی در `installer-output\AniWiFi-Setup-1.0.0.exe` ساخته می‌شود. برای آزمایش بدون نصب، `dist\AniWiFi\AniWiFi.exe` را اجرا کنید. همه فایل‌های پوشه `dist\AniWiFi` برای نسخه بدون Installer لازم هستند. **برای ساخت EXE قابل اجرای ویندوز، فرایند ساخت باید روی ویندوز اجرا شود.**

## روش استفاده در کافی‌نت

1. رایانه را به وای‌فای محلی وصل کنید؛ گوشی مشتری باید روی **همان شبکه** باشد. اینترنت لازم نیست. اگر روتر دارید، اینترنت روتر می‌تواند قطع باشد، فقط ارتباط LAN فعال باشد.
2. اگر هیچ وای‌فای موجود نیست، ابتدا دکمه «تلاش برای ایجاد هات‌اسپات ویندوز» را امتحان کنید. این روش فقط روی کارت‌های سازگار با `Hosted Network` و گاهی با دسترسی Administrator کار می‌کند؛ **روی بسیاری از کارت‌های وای‌فای جدید پشتیبانی نمی‌شود**. در صورت شکست، از **Settings → Network & Internet → Mobile hotspot** ویندوز استفاده کنید؛ این هم به قابلیت سخت‌افزار و تنظیمات ویندوز وابسته است. در صورت عدم پشتیبانی، به یک روتر/اکسس‌پوینت کوچک نیاز دارید.
3. پس از ایجاد شبکه، «بازخوانی شبکه / QR» را بزنید و IP همان شبکه را انتخاب کنید (برای هات‌اسپات معمولاً `192.168.137.1`، ولی قطعی نیست).
4. مشتری ابتدا به وای‌فای وصل شود؛ در حالت Hosted Network ساخته‌شده توسط برنامه، کد QR کوچک وای‌فای یا نام و رمز زیر آن را استفاده کند. **کد QR بزرگ صرفاً صفحه ارسال فایل را باز می‌کند و خودش وای‌فای را وصل نمی‌کند.**
5. مشتری با دوربین گوشی QR بزرگ را اسکن، فایل‌ها/عکس‌ها را انتخاب و ارسال کند. نوار پیشرفت، توقف، ادامه، لغو، سرعت و ارسال هم‌زمان در خود مرورگر نمایش داده می‌شود.
6. پس از تکمیل، «باز کردن پوشه مشتری» را بزنید. برای مشتری بعدی «نوبت جدید / QR جدید» را فشار دهید؛ لینک مشتری قبلی باطل می‌شود و فقط بخش‌های ناقص حذف می‌شوند.
7. برای تغییر پوشه مقصد یا محدودیت‌ها، مقادیر را تعیین کرده و «ذخیره تنظیمات» را بزنید؛ **از نوبت بعد** اعمال می‌شوند.

### اگر گوشی صفحه QR را باز نمی‌کند

- اتصال گوشی و رایانه به یک شبکه، **خاموش بودن Client Isolation / AP Isolation** در روتر، فعال بودن Wi-Fi گوشی و صحیح بودن آدرس IPv4 انتخابی را بررسی کنید.
- نخستین بار هنگام پرسش Windows Defender Firewall برای برنامه، ارتباط **Private networks** را مجاز کنید (ممکن است اجازه Administrator لازم باشد). شبکه را ترجیحاً Private تنظیم کنید؛ برنامه را روی وای‌فای عمومی اجرا نکنید.
- اگر اینترنت گوشی روشن است و مرورگر صفحه را باز نمی‌کند، اتصال Wi-Fi را حفظ کنید و آدرس `http://<IP>:<PORT>` را بررسی کنید (لینک کامل توکن‌دار فقط روی QR است). گاهی خاموش‌کردن موقت دیتای موبایل به انتخاب مسیر درست کمک می‌کند.
- تغییر IP، تعویض شبکه یا پایان نوبت، QR قبلی را نامعتبر می‌کند؛ دوباره اسکن کنید.

## توقف/ادامه و فایل‌های حجیم

- هر فایل به بخش‌های ۴MiB تقسیم می‌شود. بخش تکمیل‌شده روی دیسک ذخیره می‌شود و در همان نوبت نیازی به آپلود مجدد ندارد.
- برای توقف، دکمه توقف کنار فایل یا «توقف همه» را بزنید؛ هنگام ادامه، فهرست بخش‌های ذخیره‌شده از رایانه پرسیده می‌شود. پس از قطع شبکه یا بستن صفحه نیز **همان فایل‌ها را مجدداً انتخاب کنید**. مرورگر امکان بازیابی خودکار مجوز دسترسی به فایل پس از بسته‌شدن را ندارد.
- برای حداکثر سرعت، گوشی و رایانه از Wi-Fi 5GHz یا 6GHz با سیگنال خوب استفاده کنند؛ سرعت نهایی به کیفیت وای‌فای، دیسک، گوشی و مرورگر بستگی دارد. چند ارسال هم‌زمان همیشه سریع‌تر از یک ارسال نیست.
- iOS ممکن است ارسال را با قفل صفحه، خروج از Safari یا کمبود حافظه معلق کند؛ مرورگر را باز نگه دارید. صدها فایل بسیار حجیم را بهتر است در چند دسته انتخاب کنید.

## امنیت و حریم خصوصی

- لینک هر نوبت یک توکن تصادفی ۲۵۶بیتی دارد؛ API بدون توکن، از نوبت دیگر یا از Origin دیگر دسترسی نمی‌دهد. پوشه‌ها مجزا هستند.
- فایل‌ها صرفاً در پوشه انتخابی روی همان کامپیوتر ذخیره می‌شوند؛ هیچ سرویس ابری، CDN، دامنه یا حسابی وجود ندارد.
- ارتباط **HTTP داخل Wi-Fi است، نه HTTPS**. در شبکه ناامن، افراد دارای دسترسی و توان شنود ممکن است محتوا یا توکن لینک را ببینند؛ این برنامه برای شبکه خصوصی WPA2/WPA3 تحت کنترل فروشگاه طراحی شده، نه شبکه عمومی و نه ارسال محرمانه. استفاده در محیط حساس مستلزم TLS معتبر یا رمزگذاری سرتاسری است.
- فایل‌های نیمه‌کاره هنگام پایان نوبت یا خروج حذف می‌شوند. فایل‌های تکمیل‌شده **خودکار حذف نمی‌شوند**؛ حذف آرشیو برعهده مسئول فروشگاه است.
- توجه کنید محدودیت حجم و بررسی دیسک، محافظت کامل در برابر حمله‌های DoS نیست. QR را فقط به مشتری جاری نشان دهید.

## ساختار پروژه

- `wifi_app/transfer.py`: مدیریت قطعه‌ها، ادامه، پاک‌سازی، محدودیت‌ها، جداسازی نوبت.
- `wifi_app/server.py`: HTTP API محلی با aiohttp.
- `wifi_app/web/`: رابط کاملاً آفلاین گوشی (HTML/CSS/JS).
- `wifi_app/desktop.py`: کنسول فارسی ویندوزی و QR.
- `wifi_app/network.py`: یافتن IPv4 و هات‌اسپات اختیاری.
- `tests/`: تست‌های واحد و HTTP.
- `.github/workflows/build.yml`: تست Linux/Windows و ساخت Installer ویندوز.
- `installer/AniWiFi.iss`: اسکریپت Inno Setup.

## تست و محدودیت پلتفرم

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --check wifi_app/web/app.js    # اختیاری؛ چک کردن نحو جاوااسکریپت
```

تست‌های منطق ارسال و API می‌توانند روی Linux اجرا شوند؛ UI Tkinter، ساخت هات‌اسپات، Windows Firewall، سازگاری واقعی Safari/Android و نصب EXE را باید روی دستگاه‌های واقعی امتحان کرد. Workflow ویندوز EXE و Installer را می‌سازد، اما جای آزمون عملی سخت‌افزار را نمی‌گیرد.
